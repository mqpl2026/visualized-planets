引力透镜法测系外行星 · 完整理论推导

从爱因斯坦偏折角，到透镜方程与爱因斯坦半径，再到放大率、Paczynski 光曲线、质量测量，最后是行星焦散探测。所有公式逐步推导，符号与上方仿真一一对应。

1光线的引力偏折

广义相对论预言，大质量天体旁经过的光线向质量偏折。对偏折角很小的情形（θ≪1），偏折角为：

// 爱因斯坦偏折角（弱场极限，ξ 为距质量 M 的最近距离） α̂ = 4GM / (c²·ξ)

太阳边缘的星光偏折约 1.75″，是广义相对论最早的观测验证之一（1919 年日食）。注意偏折角与距离 ξ 成反比——这是透镜成像非平凡（成两个像）的根源。

2透镜方程

设透镜（质量 M）在距离 D_L 处，背景源在 D_S 处，D_{LS}=D_S-D_L。用薄透镜近似，把偏折光线与「无透镜直线」在透镜面比较，得标量透镜方程（角位置以透镜中心为原点）：

// β：源真位置；θ：像位置（均为角位置） β = θ − (D_LS/D_S)·α̂(θ) = θ − θ_E²/θ

这是一个二次方程，故点透镜总是产生两个像（除完美对齐外）。

3爱因斯坦半径

当源、透镜、观测者完美对齐（β=0）时，像退化为一个环——爱因斯坦环，其角半径即爱因斯坦半径。由透镜方程 β=0 解出：

θ_E = √[ (4GM/c²)·(D_LS/(D_L·D_S)) ] // 这是透镜法的「标尺」：一切角量都以 θ_E 为单位

量级感：一个 0.5 M☉ 透镜、源在银河系另一头（D_L=4, D_S=8 kpc），θ_E≈0.7 mas（毫角秒）。行星探测正是围绕这个极小的角尺度做文章。

4像的位置

解透镜方程 θ² − βθ − θ_E² = 0，得两个像的角位置：

θ_± = ½·( β ± √(β² + 4θ_E²) )
  • θ₊ > 0：与源同侧，|θ₊| ≥ θ_E（在爱因斯坦环外、靠近源一侧）。
  • θ₋ < 0：在透镜另一侧，|θ₋| ≤ θ_E（在爱因斯坦环内）。

两像总被透镜与源分开，无法直接分辨（角距 ~mas），但它们的总流量被放大——这正是可观测的量。

5放大率

像的放大率等于像面积与源面积之比。对小源，点 (β, 0) 映射到 (θ_±, 0) 的雅可比行列式给出横向放大率 μ_± = |θ_±/β · dθ_±/dβ|^{-1}。代入得：

μ_± = ¼·( (u²+2)/(u√(u²+4)) ± 1 ) , u ≡ β/θ_E

总放大率是两者之和（±1 项相消）：

A(u) = (u²+2) / (u·√(u²+4))

关键性质：A ≥ 1 恒成立（透镜只会增亮，不会变暗），且 u→0 时 A→∞（真实物理中由源的有限尺寸限制峰值）。

6Paczynski 光曲线

微透镜事件源于透镜与源的相对自行 μ。取源轨迹为直线、冲击参数 u₀（最接近时的 u），则任意时刻：

u(t) = √[ u₀² + ((t−t₀)/t_E)² ]

其中 t_E = θ_E/μ 是爱因斯坦穿越时间——源走过一个爱因斯坦半径所需时间。代入总放大率得 Paczynski (1986) 光曲线：

A(t) = (u(t)²+2) / (u(t)·√(u(t)²+4))

特征：对称、非周期、孤立的「钟形」增亮。峰值放大率仅由冲击参数决定：

A₀ = (u₀²+2)/(u₀·√(u₀²+4)) ≈ 1/u₀ (u₀≪1)

注意：微透镜事件不可重复（相对天体永远分离过去），这与凌星/视向速度的周期性信号本质不同。

7质量测量：微透镜的独门绝技

由观测得 t_E（光曲线宽度）与 μ（自行，可由透镜/源的视线速度或天体测量得出），得 θ_E = μ·t_E。代入第 3 节反解质量：

M = (c²/4G)·θ_E²·(D_L·D_S/D_LS) = (c²/4G)·(μ t_E)²·(D_L D_S/D_LS)
为何重要：视向速度法只能给 M_p sin i，凌星法只能给半径。微透镜法直接给真实质量（无 sin i），且能探测不发光的暗天体——流浪行星、褐矮星、恒星级黑洞。这是它不可替代的原因。

若再测得视差（地球轨道运动使光曲线轻微不对称，π_E）或透镜轨道运动，可完全分解 M_L 与 M_p，并得轨道几何。

8行星探测：焦散（Caustic）

当透镜是双体（恒星 + 行星，质量比 q=M_p/M★≪1、投影分离 s 以 θ_E 为单位），透镜方程不再解析。但奇异性告诉我们：存在焦散线——源与之相切时放大率发散（真实物理中由源尺寸限制）的曲线。

行星在焦散附近制造一个小尺度扰动：当源轨迹穿过行星焦散，光曲线上出现短暂的尖峰/凹陷。焦散尺寸约 ~√q·θ_E，扰动持续时间约 ~√q·t_E：

\text{行星异常：} \Delta t \sim \sqrt{q}\,t_E,\quad \text{幅度} \sim \sqrt{q}
  • 木星 q≈10⁻³：异常 ~数小时、幅度 ~百分之几。
  • 地球 q≈3×10⁻⁵：异常 ~数十分钟、幅度 ~千分之几——需 <1% 测光精度的连续监测（如 KMTNet、Roman 空间望远镜）。
探测概率低：行星焦散只占据轨迹的一小段，且必须恰好穿过。统计上，检测到行星的概率约 ~√q·(某因子)，故微透镜发现的行星是随机抽样（不偏向短周期），能揭示长周期与冷行星——这是凌星法（偏短周期）无法触及的群体。

本仿真的行星信号为简化叠加模型（在源轨迹穿过行星附近时叠加一个幅度 ∝√q、宽度 ∝√q·t_E 的凸起），用于定性展示；真实拟合需完整双体透镜建模。

9历史与科学意义

1986，Bohdan Paczyński 提出用微透镜探测银河系暗物质晕中的大质量致密晕天体（MACHO），预言了特征光曲线。1990 年代 MACHO/EROS/OGLE 合作组据此未能发现足够暗物质，但开辟了一个全新领域。

2004 起，微透镜开始用于行星：OGLE-2005-BLG-390Lb（2006）是人类首批通过微透镜发现的系外行星之一，一颗约 5.5 M⊕ 的「冷」行星，证明微透镜能找到远离宿主、凌星法看不见的行星。

如今 MOA、OGLE、KMTNet（全球三台 1.6 m 望远镜接力监测）已发现百余颗微透镜行星，包括地球质量级的 MOA-2007-BLG-192Lb 与流浪行星候选者。下一代 Roman 空间望远镜（2020 年代后期）预计每年发现数百颗微透镜行星，大幅拓展对银河系行星分布的认知。

三种方法并置的意义：凌星法 → R_p（偏小质量、有几何偏置）；视向速度法 → M_p sin i（偏大质量、可测不凌星者）；微透镜法 → M（真实质量、暗天体、冷行星）。三者交叉验证，才构成今天系外行星科学的完整图景。
