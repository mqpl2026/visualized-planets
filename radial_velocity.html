1行星在拉动恒星

行星与恒星其实围绕两者的共同质心转。恒星被拽出的轨道半长径为 a★ = ap · Mp / (M★ + Mp)， 因此行星越重、离恒星越近，恒星就摆得越明显。

a★ = a_p · M_p / (M★ + M_p)

木星在太阳中引起的 a★ 约 742 Gm（约为日地距离的 0.5%）； 地球引起的仅约 449 km。这就是该方法对大质量、短周期行星最敏感的原因。

2多普勒效应：速度 → 频移

观测者沿视线方向只接收到恒星速度的 X 分量。根据多普勒公式，谱线波长随之平移：

Δλ/λ₀ = v_r / c　，　v_r > 0 → 红移

恒星接近时谱线蓝移、变短；远离时红移、变长。 在上方光谱图中，把窗口放大到 Å 量级就能直接看到整条谱系的平移。

典型恒星吸收线附近的分辨本领要求 vr 测量精度需优于 1 m/s（≈ 3×10-9 的相对波长精度）。

3开普勒运动 → 速度曲线

圆轨道给出正弦曲线；偏心轨道则变成非正弦的“尖峰”形——近星点走得快，远星点走得慢。 由开普勒第三定律与角动量守恒可导出：

v_r(t) = K[cos(ν+ω) + e·cos ω] + γ
K = (2πG/P)1/3 · M_p sin i / (M★+M_p)2/3 · (1−e²)−1/2

所以曲线振幅直接给出 Mp sin i，而不是 Mp 本身。

4为什么只能给出 M sin i？

倾角 i 是视线与轨道法线的夹角。若轨道侧视（i = 90°），恒星摆幅全部落在视线方向， K 最大；若轨道正对观测者（i → 0°），恒星前后摆动完全不可见。

M_p sin i = K(1−e²)1/2 M★2/3 (P/2πG)1/3

因此 RV 法永远得到行星质量的下限。想要真实质量，需要凌日法（i ≈ 90°）、 天体测量或微透镜给出独立约束。把「假设倾角」调到 90° 以外的小角度，就能直观看到低估有多严重。

5真实观测是怎么做的

光谱被切成数十阶，每阶提取成相关函数（CCF），其重心给出一次 vr 测量。 每次曝光带来几 m/s 的随机误差，且需要长时间基线才能锁定周期：

· 1–2 个周期：只能看到摆动，周期与质量都高度不确定。
· 5–10 个周期：周期锁定，K 可测，M sin i 收敛。
· 多年：还能测出行星质量随时间的小幅变化 → 检出额外行星。

试着把采样间隔调大、噪声调高，观察数据点如何逐渐「淹没」信号。

1两体问题与共同质心

恒星（质量 M★）与行星（质量 M_p）在相互引力下绕共同质心运动。设质心位于原点，由定义：

M★·r★ + M_p·r_p = 0 // 质心条件 ⟹ r★ = −(M_p/(M★+M_p))·r , r_p = (M★/(M★+M_p))·r 其中 r = r_p − r★ 为相对位置矢量。

恒星轨道的半长径因此为：

a★ = a_p · M_p / (M★ + M_p)

量级感：木星使太阳的 a★≈742 Gm（日地距离的 0.5%）；地球仅 ≈449 km。这正是 RV 法对大质量、短周期行星最敏感的根本原因。

2相对轨道与开普勒第三定律

两体问题可化为一个约化质量 μ=M★M_p/(M★+M_p) 在中心势 −GM★M_p/r 中的运动。相对运动满足：

// 比机械能守恒（椭圆轨道 e<1） ε = v²/2 − G(M★+M_p)/r = −G(M★+M_p)/(2a) // 角动量守恒 → 面积速度恒定（第二定律） h = |r × v| = √[G(M★+M_p)·a(1−e²)] // 周期 T = 2π·a / v̄ = 2π√[a³/G(M★+M_p)] ⟹ a³ = G(M★+M_p)·P²/(4π²) // 开普勒第三定律（牛顿形式）

3开普勒方程：从时间到位置

引入偏近点角 E、平近点角 M、真近点角 ν。平近点角随时间均匀推进：

M = n·(t − τ) , n = 2π/P = √[G(M★+M_p)/a³]

几何关系给出开普勒方程（超越方程，需求解 E）：

M = E − e·sin E

用牛顿迭代求解（本仿真即用此法）：E_{k+1}=E_k − (E_k−e sin E_k−M)/(1−e cos E_k)。再由 E 求 ν 与 r：

r = a(1 − e·cos E) tan(ν/2) = √[(1+e)/(1−e)]·tan(E/2)

4轨道速度

对 r=a(cos E−e, √(1−e²) sin E) 关于时间求导，并用 dE/dt = n/(1−e cos E)：

\vec v = (n·a / (1 − e·cos E))·(−sin E, √(1−e²)·cos E) // 速度大小（vis-viva 方程） v² = G(M★+M_p)·(2/r − 1/a)

近星点速度最大、远星点最小——这正是偏心轨道 RV 曲线呈尖峰状的来源。

5视向速度投影

观测者沿 +X 无穷远处看向原点，只能感知速度的 X 分量。设轨道面相对视线倾斜 i、近星点方向偏离 ω。将轨道面内坐标 (x',y') 旋转：

x = x'·cos ω − y'·sin ω // 视线方向 y = (x'·sin ω + y'·cos ω)·cos i z = (x'·sin ω + y'·cos ω)·sin i v_r = dx/dt + γ // γ 为视向速度系统性偏移（恒星本动 + 仪器）

只有 i=90°（侧视）时全部速度落在视线方向；i→0° 时摆动消失。这就是 sin i 模糊的几何起源。

6半振幅 K 与质量函数

把第 4、5 节合起来，视向速度半振幅定义为 K = |v_r|_max（相对 γ）。整理得 RV 法的核心公式：

K = (2πG/P)^(1/3) · (M_p sin i)/(M★+M_p)^(2/3) · (1−e²)^(−1/2)

这就是质量函数。反解行星质量：

M_p sin i = K·(1−e²)^(1/2)·(M★+M_p)^(2/3)·(P/2πG)^(1/3) // 当 M_p≪M★ 时（绝大多数情况）： M_p sin i ≈ K·(1−e²)^(1/2)·M★^(2/3)·(P/2πG)^(1/3)
关键：RV 法直接给出的是 M_p sin i，是行星真实质量的下限。要得到真实质量需独立约束 i（凌星法、天体测量或微引力透镜）。

7正弦曲线（圆轨道特例）

当 e=0、ω=0、i=90° 时，ν=M=2π t/P，代入得纯正弦：

v_r(t) = K·cos(2π t/P) + γ

一般情形（任意 e,ω,i）的完整表达式：

v_r(t) = K·[cos(ν(t)+ω) + e·cos ω] + γ

曲线形状编码了轨道偏心率与朝向；周期 P 给出轨道尺寸（经开普勒定律），振幅 K 给出 M_p sin i。

8观测极限与噪声

实测 v_r 的精度受限于光子噪声、恒星活动（星斑、振荡、耀发）与仪器。恒星本身的抖动（jitter）量级约 0.5–3 m/s（宁静星）到 10–50 m/s（活动星）。可探测的最小 K 近似：

K_min ≈ √(σ²/N + S_jitter²)·(某个置信因子) // σ 单次测速精度, N 观测数, S_jitter 恒星抖动

长期监测的回报：① 1–2 周期 → P 与 K 高度简并；② 5–10 周期 → M_p sin i 收敛；③ 多年基线 → 测出 K 的微小变化，暗示第二颗行星（n-body 拟合）。

常见陷阱：① 视向速度偏移 γ 会随恒星在银河中运动而变；② 恒星自转、斑点会引入周期性伪信号（与行星周期混淆）；③ 需要独立证认（凌星、直接成像、天体测量）来确认行星而非棕矮星/恒星。

9历史与探测

1995 年，Michel Mayor 与 Didier Queloz 在 Haute-Provence 用 ELODIE 阶梯光栅光谱仪发现飞马座 51 b： P=4.23 天、K≈56 m/s——一颗热木星，公转周期比水星还短，彻底颠覆了行星形成理论（行星迁移）。二人获 2019 年诺贝尔物理学奖。

三十余年后，视向速度法与凌星法共同把确认的系外行星推过 5000 颗，并首次测到地球质量级行星（Proxima b、GJ 667Cc、TRAPPIST-1 系统）。当前前沿：用 ESPRESSO、EXPRES 等 <10 cm/s 的光谱仪寻找真正位于宜居带的岩质地球。

为什么仍重要：凌星法只能测半径、且有几何偏置；RV 法测质量、可探测不凌星的行星。两者结合给出密度，是区分岩质／气态／冰质行星的唯一途径。这正是本仓库两个页面并置的意义。
