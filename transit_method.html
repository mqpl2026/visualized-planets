凌星法测系外行星 · 完整理论推导

1几何与坐标约定

设观测者沿 +X 方向无穷远处看向原点（与视向速度法采用同一约定，便于对比）。天球平面（sky plane）是垂直于视线的 Y–Z 平面。行星绕恒星做开普勒运动，轨道面相对天球平面倾斜 i（i=90° 为侧视，i=0° 为俯视）。

采用近焦点角 ω、偏心率 e、真近点角 ν。行星在轨道面内的位置分量为：

// 轨道面内坐标（r 为到恒星距离） r = a(1 − e²) / (1 + e·cos ν) x' = r·cos ν // 指向近星点 y' = r·sin ν // 旋转 ω（面内）再倾斜 i（绕视线 X 轴） x = x'·cos ω − y'·sin ω // 视线方向分量 y = (x'·sin ω + y'·cos ω)·cos i // 天球平面 z = (x'·sin ω + y'·cos ω)·sin i

行星在天球平面上的投影到恒星中心的角距离（以恒星半径 R★ 为单位）决定凌星与否。记 d(t)=√(y²+z²)，则：

d(t) = |r·sin(ω + ν)|

当 d < 1 + k（其中 k ≡ R_p/R★）且行星位于观测者一侧（x>0）时，发生凌星。凌星过程中 d 的最小值即冲击参数：

b = (a·cos i / R★)·(1 + e·sin ω)/(1 − e²) // 最小值 = 0 为正掠，b≥1+k 不凌星

2流量亏损与凌星深度

设恒星总光度为 L★。凌星时行星剪影挡住了一部分恒星光。若忽略临边昏暗（均匀恒星盘面），被挡掉的流量正比于被掩面积。当行星完全落在恒星盘内（d ≤ 1−k，即平底部分）：

被挡面积 = π·R_p² δ ≡ ΔL/L = (π R_p²)/(π R★²) = (R_p/R★)² = k²

这就是凌星深度。它只依赖半径比，与距离、质量无关——这是凌星法最干净的可观测量。代入量级：

  • 地球绕太阳：k=(6371/695700)=0.00916 → δ≈84 ppm（需极高精度测光，如 Kepler/TESS 的窄视场或 PLATO）。
  • 热木星（如 51 Peg b）：R_p≈11 R⊕, R★≈1.2 R☉ → δ≈1.1%，地基望远镜即可探测。
关键：深度给出的是真实半径比，没有 sin i 模糊。这与视向速度法只能给 M_p sin i 形成鲜明对比——两种方法是互补的。

部分凌星（1−k < d < 1+k）时，掩食区是两个圆的交叠。设两圆半径为 R★ 与 R_p、圆心距 d，交叠面积为：

A = R_p²·cos⁻¹[(d²+R_p²−R★²)/(2 d R_p)] + R★²·cos⁻¹[(d²+R★²−R_p²)/(2 d R★)] − ½·√[(−d+R_p+R★)(d+R_p−R★)(d−R_p+R★)(d+R_p+R★)] δ(d) = A / (π R★²) // 均匀盘近似

3临边昏暗（Limb Darkening）

真实恒星边缘（临边）比中心暗。最常用的二次临边昏暗定律，以视线与局部法线夹角 θ（μ=cos θ）描述比强度：

I(μ) = I₀·[ 1 − u₁(1−μ) − u₂(1−μ)² ], μ = √(1 − ρ²), ρ = r/R★

其中 ρ 是盘面坐标。此时总流量需对盘面积分，深度不再恰为 k²，且凌星底部呈圆弧形而非平底（因为行星压过不同 μ 的区域，强度不同）。精确流量需 Mandel & Agol (2002) 的椭圆积分公式；本仿真用盘面数值积分（把恒星盘离散为极坐标网格，逐格判断是否被行星覆盖）来体现这一效应。

物理后果：临边昏暗使凌星更浅、底部变圆、 ingress/egress 更陡。u₁,u₂ 由恒星大气模型与测带波长决定（例如太阳光学波段 u₁≈0.45, u₂≈0.22）。

4凌星时长

定义 T₁₄ 为第一次到第四次接触（整个凌星历时），T₂₃ 为第二次到第三次接触（平底部分）。先考虑圆轨道（e=0）。

4.1 圆轨道

凌星时行星在天球平面上以近似匀速 v_sky = (2π a/P)·(sin i) 扫过弦长。被扫过的弦长为 2R★√((1+k)²−b²)（几何：圆心在弦的垂足上，半弦长 R★√((1+k)²−b²)，两端再算进 kR★ 的 ingress）。于是：

T₁₄ = (P/π)·arcsin[ (R★/a)·√((1+k)² − b²) / sin i ] // 小量近似 (R★/a≪1)： T₁₄ ≈ (P·R★ / π a)·√((1+k)² − b²) / sin i // 平底时长（仅当 b < 1−k 存在）： T₂₃ ≈ (P·R★ / π a)·√((1−k)² − b²) / sin i

4.2 偏心轨道修正

偏心率使行星在凌星附近速度不再是 2πa/P，且凌星发生在星历的某个真近点角处。引入 e 与 ω 的修正因子（Winn 2010）：

T₁₄ = (P/π)·arcsin[ (R★/a)·√((1+k)²−b²)/sin i ]·(√(1−e²)/(1+e·sin ω))

括号中的 (1−e²)^{1/2}/(1+e sin ω) 是动力学修正：若凌星发生在近星点附近（ω≈90°），行星走得快，凌星更短；远星点（ω≈270°）则更长。

5开普勒第三定律

行星（质量 M_p）绕恒星（质量 M★）的总质量 M=M★+M_p。由牛顿引力 + 圆周近似（或角动量守恒）得周期与半长径的关系：

// 向心力 = 引力： M_p·v²/a = G·M★·M_p/a² v = 2π a / P ⟹ a³ = G·M·P² / (4π²) // 开普勒第三定律（牛顿形式）

这是把时间量（P）与几何量（a）联系起来的桥梁。注意式中含 M，所以仅凭周期无法定距离，除非知道质量（或由凌星几何反推，见下节）。

6恒星密度反演（凌星法最深刻的结论）

Seager & Mallén-Ornelas (2003) 指出：凌星几何 + 开普勒定律可以直接给出恒星的平均密度，而不需要知道恒星质量或半径各自是多少！

由第 4 节时长公式（圆轨道、小量近似）解出 a/R★：

a/R★ = (P/π T₁₄)·√((1+k)² − b²) / sin i

把它代入开普勒定律的密度形式。ρ★ = M★ / (4/3 π R★³)，由 a³=GM★P²/4π² 得 M★ = 4π²a³/(G P²)，于是：

ρ★ = M★ / (4/3 π R★³) = [4π² a³/(G P²)] / (4/3 π R★³) = (3π / G P²)·(a/R★)³ ρ★ = (3π / G P²)·(a/R★)³ // 与 M★、R★ 各自无关！
意义：只要测出 P 和 a/R★（由凌星时长），就得到 ρ★。这能独立验证恒星模型、识别蚀食双星污染，并在缺乏光谱质量时仍能约束系统。若进一步假设恒星类型（如主序），即可由 ρ★ 推出 R★ 与 M★。

更精细的做法：同时拟合 T₁₄ 与 T₂₃ 两个时长，可联立解出 b 与 a/R★，无需假设 i。

7行星半径与轨道距离的确定

7.1 行星半径

由深度直接得到半径比，再乘以恒星半径：

R_p = R★·√δ // δ 为实测深度

若 R★ 已知（光谱学 + 密度约束），R_p 即为真实值。地球半径 R⊕=6371 km，木星半径 R_J=71492 km，太阳半径 R☉=695700 km。

7.2 轨道半长径

有了 a/R★ 与 R★：

a = (a/R★)·R★ // 天文单位 AU = 1.496×10¹¹ m

若用第 6 节的密度关系代入，也可写成 a = [G M★ P²/(4π²)]^{1/3}，两种途径互为检验。

8几何凌星概率

并非所有行星都会凌星——轨道面必须恰好侧对我们。设轨道法线与视线的夹角为 i，发生凌星要求 cos i ≤ (R★+R_p)/a（对圆轨道）。若轨道取向在 cos i 上各向同性，则：

P_transit = (R★ + R_p)/a = (R★/a)(1 + k)

量级：地球 (R☉/1AU)=0.0046 → 0.46%；热木星（a=0.05 AU）≈10%。这解释了为何凌星法发现的行星强烈偏向短周期大半径——它们既更容易凌星，也更容易被多次凌星的周期确认。偏心轨道的概率为 (R★/a)(1+e sin ω)/(1−e²)。

9与视向速度法结合：从半径到密度

凌星法给 R_p，视向速度法给 M_p sin i。当同一行星既被凌星又被测到视向速度时，凌星意味着 i≈90°，于是 sin i≈1，RV 的模糊被解除，得到真实质量：

// 凌星确认 i≈90° ⟹ sin i≈1 M_p = K·(P/2πG)^{1/3}·M★^{2/3}·√(1−e²) // RV 质量函数 // 行星平均密度 ρ_p = M_p / (4/3 π R_p³) = 3 M_p / (4π R_p³)

密度是判断行星成分的关键：约 5.5 g/cm³ 为类地（岩石+铁），约 1.3 g/cm³ 为富水/冰巨星，约 0.3 g/cm³ 为气态巨行星。这正是 2000 年代以来大量「超级地球」「亚海王星」被分类的物理基础。

常见系统误差：① 未考虑的食双星（背景星被行星状天体凌星）可伪造深度，需 RV 或色差（不同波段深度不同）证伪；② 恒星半径若估错 10%，R_p 就错 10%（R_p∝R★）；③ 第三光（双星伴光）会稀释深度使 R_p 偏小；④ 活动区/黑子造成测光噪声与伪凌星。

历史：1999 年首次确认系外行星 HD 209458 b 被凌星（Charbonneau et al.）；2000 年代 Kepler 太空望远镜（2009–2018）以凌星法发现数千行星并测得其半径分布，开启了「宜居带」统计（如 TRAPPIST-1 七行星系统）。
